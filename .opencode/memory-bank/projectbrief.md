# Project Brief

## Overview
Personal tech blog built with Hugo static site generator, using the Terminal theme by panr.

## Core Requirements
- Static blog for publishing tech articles, tutorials, and personal thoughts
- Multi-language support (English and Portuguese-BR)
- Deployed as GitHub Pages at blog.sconetto.me
- RSS feed for content subscription
- Agent support via memory bank for future development

## Technology Stack
- Hugo 0.153.2 (extended)
- Go 1.25.5
- Node.js 24.12.0
- Dart Sass 1.97.1
- Terminal theme (hugo-theme-terminal v4)

## Repository
- Location: ~/Desktop/personal/git/hub/tech-blog
- Deployed: GitHub Pages (main branch)
- CI/CD: GitHub Actions (hugo.yaml)
